# Replies to comments

Read `.claude/ig-brands.md` first for the brands, voice, language and rules. If it is missing, ask the user for the account, niche, audience and language.

## Steps

1. Take the comments the user pasted or screenshotted, and the post they
   are on.
2. Write one reply per comment, 1–2 sentences, in the commenter's
   language:
   - question: answer it directly, then invite the next step
   - price or booking enquiry: give the detail if the user supplied it,
     otherwise say you are sending it by DM, and draft that DM too
   - praise: thank them and add something specific, or ask a question
     back to keep the thread going
   - complaint: acknowledge it, do not argue, offer to sort it out in DM
   - spam or abuse: recommend hiding or deleting, with no reply
3. Use the person's name when it is visible.

## Rules

Never state a price, date or seat count the user has not given. Do not
use the same reply twice in one batch.
