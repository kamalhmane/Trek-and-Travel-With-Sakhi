# Comments on other accounts

Read `.claude/ig-brands.md` first for the brands, voice, language and rules. If it is missing, ask the user for the account, niche, audience and language.

## Steps

1. Work from the post the user describes, pastes or screenshots.
2. Write 3–5 comment options, each 1–2 sentences, that respond to
   something specific in that post: a detail, a question, or a short
   related experience.
3. Match the language of the post.

## Rules

- No promotion, no "check our page", no links, no copy-paste lines such
  as "Nice post!".
- Do not write comments meant to be posted in bulk on many accounts, and
  do not write fake customer comments or reviews.
- If asked for a routine, suggest a small daily habit: a handful of
  thoughtful comments on local trekking, travel and history pages.
