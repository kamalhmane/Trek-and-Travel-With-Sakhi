# Repurpose content

Read `.claude/ig-brands.md` first for the brands, voice, language and rules. If it is missing, ask the user for the account, niche, audience and language.

## Steps

1. Take the source the user gives: a Reel script, post, trip itinerary,
   customer review, website text or notes.
2. Pull out the 3–5 strongest points, facts or moments in it.
3. Produce, from those points:
   - a Reel outline (hook and 4–6 shots)
   - a carousel outline (slide headings)
   - a 4–5 frame Story sequence with one sticker
   - a standalone caption
   - 2 short quote or tip lines for single-image posts
4. Give each piece a different angle so they do not repeat each other.

## Output

One block per format, then a suggested order and spacing for posting
them. Offer to expand any block with `ig-reel`, `ig-carousel`, `ig-story`
or `ig-caption`.

Only reuse customer reviews, photos or names the user says they have
permission to use.
