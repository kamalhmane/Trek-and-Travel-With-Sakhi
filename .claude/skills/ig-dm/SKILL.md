# Instagram DMs

Read `.claude/ig-brands.md` first for the brands, voice, language and rules. If it is missing, ask the user for the account, niche, audience and language.

## Steps

1. For a pasted DM: reply in the sender's language, in 2–4 short lines.
   Answer the question first, then give one clear next step (date
   options, how to book, what to send).
2. For templates: write saved replies for the common cases, each with a
   shortcut word:
   - trip details and price
   - how to book and pay
   - what to bring and fitness level
   - pickup points
   - follow-up when someone went quiet
   - thank-you after the trip, asking for a review
3. Mark every fact that must be filled in, such as [date], [price],
   [number], unless the user has given it.

## Rules

- Reply only to people who messaged first or asked for details. Do not
  write cold mass DMs to strangers.
- No pressure tactics or false "last seat" claims.
- For a collaboration request, draft a polite reply and list what the
  user should check before agreeing.
