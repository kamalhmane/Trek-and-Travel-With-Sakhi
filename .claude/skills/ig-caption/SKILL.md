# Instagram captions

Read `.claude/ig-brands.md` first for the brands, voice, language and rules. If it is missing, ask the user for the account, niche, audience and language.

## Steps

1. Find out what the post shows and what it should achieve. If the user
   shared the image, video script or idea, work from that.
2. Write 3 options in different styles: short and punchy, storytelling,
   and informative.
3. In each, the first line must make sense on its own, because Instagram
   cuts the caption off after it.
4. Add one call to action per caption, matched to the goal: save, share,
   comment a keyword, or DM to book.
5. Add 3–5 niche hashtags at the end. No generic tags such as #viral.

## Rules

- Short lines and line breaks. Emoji sparingly, never one per line.
- Trip details (place, date, price, contact) only when the user gave them.
- Say which option you would post and why, in one line.
